Лисюша PWA iPhone v24

Это WEB/PWA-версия на JavaScript для Safari/iPhone.
1. Разместите содержимое папки на HTTPS-хостинге.
2. Откройте index.html в Safari.
3. Нажмите «Поделиться» → «На экран Домой».
4. После первого запуска игра кэшируется и может работать офлайн.

Важно: локальный HTML-файл в просмотрщике Files/ChatGPT не является полноценным PWA и может блокировать JavaScript или Service Worker.
